# Lukisan Kejuruteraan

Static HTML learning website for Lukisan Kejuruteraan.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Entry points

- `index.html` — cover page
- `mainmenu.html` — chapter menu
- `chapter1.html` through `chapter13.html` — learning chapters

## Media

The `images/` and `video/` directories are ignored by Git. Copy or host these assets separately when deploying the website.
